Raeburn Shield, replayed.

What if some Test matches had never happened? Remove a share of rugby history, replay the lineal championship, and see which nations' fortunes change.

The experiment

Edit history at random.

Every simulation independently removes each recorded Test in the selected years with the probability you choose. Scores never change; only the set of matches does.

Small omissions can reroute the Shield for decades. Run the same counterfactual many times to reveal a distribution rather than one lucky timeline.

Method & data

What this does, and what it doesn't.

Longest streak is the greatest number of consecutive successful defences during one tenure. A draw counts as a defence, as it does under the usual Shield rule.

Successful defences counts every retained challenge across the whole timeline. Acquisitions counts victories over the current holder; the initial award is not an acquisition.

Removing matches is a deliberately simple counterfactual. It does not model changed team strength, selection, travel, scheduling, or the knock-on effects a missing Test would have caused.

The seed makes a run reproducible. Tests are removed using a seeded pseudo-random generator in your browser. No data leaves this page.

Dataset scope. 2,727 official Tests where both teams are among Argentina, Australia, England, France, Ireland, Italy, New Zealand, Scotland, South Africa, and Wales, from 27 March 1871 through 15 July 2023. The source excludes every match involving another nation, including the Shield-changing wins by Romania, Samoa, and Japan. The simulation and gold diamonds therefore describe this ten-nation counterfactual model, not the complete official-history holder path. Source: Ad882, Rugby-match-analysis (MIT License).
